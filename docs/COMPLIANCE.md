# 合规边界

本文说明本项目的能力边界与使用者责任。**它不是法律意见**，
涉及分发、商用或批量处理时请咨询专业人士。

---

## 1. 项目定位

一个**个人数据备份工具**：在用户自己拥有、自己解锁的设备上，
把某个 App 通过其**自带功能**导出的图片，复制到用户自己的电脑上。

它不提供对任何服务的访问能力，不绕过任何鉴权，不改变任何应用的行为。

---

## 2. 能力边界（技术上做不到的事）

| 不做 | 说明 |
|---|---|
| 不读取应用私有数据 | 不访问 `/data/data/<pkg>`、不读数据库、不读内存 |
| 不破解、不解密、不逆向 | 不分析协议、不提取密钥、不修改安装包 |
| 不绕过鉴权 | 不模拟登录、不使用他人账号、不访问服务端接口 |
| 不修改应用 | 不注入、不 hook、不 patch、不重打包 |
| 不联网 | 除 `127.0.0.1` 本地服务外不发起任何请求 |
| 不分发素材 | 仓库不含任何图片、音频、字体、客户端文件 |

工具的全部能力是：**截屏 → 模板匹配 → 模拟点击 → 复制新产生的文件**。
这与"用户自己用手指点保存"在行为上等价。

---

## 5. 数据留存与删除

| 位置 | 内容 | 删除方式 |
|---|---|---|
| `archive/` | 导出的图片与清单 | 直接删除目录 |
| `probe/` | 运行日志、临时截图、状态文件 | 直接删除目录 |
| `templates/` | 运行时裁出的模板图 | 直接删除目录 |
| 手机相册目录 | 应用自己导出的原图 | 用页面上的「清理重复副本」，或手动删除 |

**本工具不收集、不上传、不备份到云端任何内容**；卸载/删除目录即彻底清除。

2. **不要**把导出的图片打包进 Release 产物。
3. **不要**在 README、截图、演示视频里使用游戏内画面。

5. 若修改后用于商业目的，请自行评估是否需要授权——本项目不授予任何
   与第三方作品相关的权利。
